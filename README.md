# Smart Library

A full-stack library management system built to replace manual record-keeping with digital book circulation, role-based access, and automated reporting.

## Problem

Manual library management is slow and error-prone: unorganized records, slow overdue tracking, time-consuming reports, and no way for students to check book availability in real time.

## Features

- **Authentication & Roles** — OTP-based student registration, separate accounts for library staff and super admins, with role-based access control
- **Public Catalog** — search books by keyword or category, check live availability
- **Circulation Desk** — issue, return, and renew books with auto-calculated due dates and overdue fines
- **Admin Analytics** — dashboard with borrowing trends and category breakdowns, exportable as PDF/CSV
- **Notifications** — overdue warnings and activity updates for users

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Tools:** Git, GitHub

## Project Status

## Getting Started

```
git clone https://github.com/<yesmzee>/smart-library.git
cd smart-library
npm install
```

Set up a `.env` file with your MySQL credentials before running the server.
